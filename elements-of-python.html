Introduction to Python

What is Python?

Python is an interpreted, dynamically-typed, and easy-to-learn programming language used worldwide by beginners and experts. It was created by Guido van Rossum in 1991. Python supports multiple programming paradigms, including procedural, object-oriented, and functional programming. Python code is executed line by line, and it can run on various operating systems — making it portable and platform-independent.

Installing & Running Python

Python is free and open-source — download it from python.org for Windows, macOS or Linux. The package bundles the interpreter and a basic editor. The interpreter is also called the Python Shell; its >>> prompt means Python is ready for a command.

REPL stands for Read-Eval-Print-Loop — Python's interactive shell where you write, execute, and test code line-by-line with immediate feedback. You can't save the statements for later use; it's built for testing single-line statements.

>>> 5+3 8 >>> 8-2 6 >>>

4.2

Python Comments

Comments explain the code to the reader — the interpreter completely ignores them while running the program. Python has two kinds.

A single-line comment begins with the # (hash) character. Anything after # on that line is a comment.

# Simple program print("Welcome to Python")
OUTPUT
Welcome to Python

Program 4.1 — the first line is ignored by the interpreter; only the print() line runs.

Python has no dedicated multi-line comment symbol. A string in triple single quotes ''' or triple double quotes """ acts as a comment if it's not assigned to a variable or used in code.

'''Program 4.2 Multi-line Comment''' print("Welcome to Python")
OUTPUT
Welcome to Python

Program 4.2 — the two lines inside the triple quotes are treated as one comment block.

4.5

Variables

A variable is a symbolic name that stores data which may change during execution. It's created with the assignment operator =.

rollno = 12 # rollno is an integer name = "Arun" # name is a string price = 85.5 # price is floating point

Dynamic typing, live

Python variables don't need a declared type — the type is decided automatically, and can change every time you reassign the variable. Press Next to reassign n and watch its type change.

n = 10
type(n) → <class 'int'>

Identity operators check whether two variables refer to the same object in memory.

x = [1, 2, 3] y = [1, 2, 3] print(x is y) # False — different objects z = x print(x is z) # True — same object in memory

Membership operators check whether a value exists inside a sequence.

a = [10, 20, 30] print(10 in a) # True text = 'Python' print('k' not in text) # True
