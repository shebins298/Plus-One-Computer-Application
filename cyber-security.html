7.1

Introduction

Cyberspace refers to interconnected networks of computers and electronic systems. It is the environment where online communication, data exchange, and digital interactions take place.

Five components of cyberspace: networks, hardware, software, data, and users.

Kerala context: digital literacy is relatively high, with initiatives such as Akshaya centres, e-District, K-FON and online education platforms. Along with convenience, technology also brings risks — cyber criminals misuse digital systems to steal money, data and personal information.

Cyber security is the practice of protecting computers, networks, devices and data from digital attacks, unauthorized access, damage, or theft. It involves using technologies, rules, and safe practices to keep information secure while using the internet and digital devices.

7.2

Vulnerability in Cyber Space

Vulnerability in cyberspace refers to weaknesses or gaps in computers, networks, software or user practices that can be exploited by cyber attackers.

Vulnerabilities arise from software flaws, human mistakes, network setup errors and weak hardware.

7.2.1.1 Software Vulnerabilities
Bugs and coding mistakes
Errors or flaws in program code. Example: an app crashing unexpectedly — that bug could let attackers sneak in.
Outdated software
Software that is not updated will have security problems; hackers can easily attack old software.
Digital footprints
The data trail created when a person uses digital devices and the internet, showing where they have been online. Examples: search history, social media activity, cookies, IP address, location data.
7.2.1.2 Human Factors
Excessive user privileges
More access rights than necessary — a compromised account can then delete data or change system settings.
Weak passwords
Easy passwords can be guessed quickly; using the same password everywhere is also unsafe.
Lack of awareness
Users who do not know basic cyber safety rules click fake links or open unknown files, letting hackers in.
Insider threats
Users who already have access to the system may misuse it or make mistakes.
7.2.1.3 Network and Infrastructure Issues
Misconfigured firewalls and routers
A firewall is a security guard for a network. Weak or wrongly configured rules can be bypassed. Routers with default settings — e.g. a factory password (the default password a device comes with from the manufacturer) — let attackers take over a home network.
Poor security settings
If security settings are not set properly, hackers can enter the network easily.
Untrusted devices or networks
Using public Wi-Fi or unknown devices can expose data to hackers.
Misconfigured cloud storage
Wrongly set access rights (e.g. public access enabled by mistake) lead to data leaks, unauthorized access, or data theft.
7.2.1.4 Hardware Vulnerabilities
Outdated / unsupported devices
Hardware that never gets security patches is weak and lacks modern security features. Example: an old smartphone that can no longer install security updates.
Insecure BIOS settings
The BIOS (Basic Input Output System) controls basic hardware operations. If BIOS passwords are not set, attackers can change settings, install malware or access data before the operating system starts.

Try Yourself — after 7.2

1. How does human error lead to cyber attacks?
Users who do not know basic safety rules click fake links or open unknown files, letting hackers in. Excessive privileges, weak passwords and insider misuse are also human causes.
2. “Using untrusted networks can expose personal data.” Justify this statement.
Public Wi-Fi and unknown devices are not under our control and their security settings cannot be trusted. Data travelling over them can be intercepted by hackers.
3. Small files used by websites to track browsing habits are called ____.
Cookies
4. Explain weak passwords with an example.
A weak password can be guessed quickly because it uses common words or personal information; using the same password on every account is also unsafe. Example: “123456”, “password”, or one’s own name with birth year.
5. What are bugs? How can they lead to cyber attacks?
Bugs are errors or flaws in the code of a program. Example: an app crashing unexpectedly — that bug could let attackers sneak in.
6. What is meant by insider threat?
Users who already have access to the system may misuse that access or make mistakes, causing harm from within.
7. What is a digital footprint?
The data trail created when a person uses digital devices and the internet; it shows where a person has been online.
8. Which hardware component controls basic system operations before the OS loads?
BIOS (Basic Input Output System)
7.3

Meaning and Scope of Cyber Security

Cyber security involves protecting information and systems from malignant activities in cyber space.

Cyber security is not only about computers. It is also about people, data and safe behavior in cyberspace.

The CIA Triad — three basic principles
PrincipleMeaning
ConfidentialityInformation should be accessible only to authorized persons.
IntegrityInformation should not be altered without permission.
AvailabilityInformation and services should be available when needed.

Example: When a student in Kerala logs into the Kerala Infrastructure and Technology for Education (KITE) portal, cyber security ensures only the student can access their account (confidentiality), the content is not tampered with (integrity), and the site stays up during exam seasons (availability).

Extended / supporting security objectives
Authentication
Verifying the identity of a user or system before granting access. Answers “Who are you?” Examples: username/password, OTP, biometrics.
Authorization
Determines what an authenticated user may do after logging in. Answers “What are you allowed to do?” Example: a student can view marks but not edit them.
Access Control Systems
Mechanisms enforcing authentication and authorization rules based on predefined rules.
Non-repudiation
Ensures a user cannot deny performing an action after it has occurred; provides proof of origin and action.
Authentication vs Authorization
Authentication
“Who are you?”
Before access is granted
Verifies identity
Authorization
“What are you allowed to do?”
After the user has logged in
Decides permissions / level of access

Try Yourself — after 7.3

1. Which of the following is NOT part of the CIA Triad? (a) Confidentiality (b) Integrity (c) Authentication (d) Availability
(c) Authentication — it is an extended supporting security goal, not one of the three core principles.
2. How is cyber security related to human behavior?
Cyber security is not only about computers — it is also about people, data and safe behavior. Weak passwords, clicking fake links and insider misuse all cause attacks, so safe user behavior is essential.
7.4

Importance of Cyber Security

India is a rapidly growing digital economy. Digital India initiatives: online banking, UPI payments, Aadhar based services, e-Governance, digital classrooms.

Kerala services depending on secure digital systems: SPARK (Service and Payroll Administrative Repository for Kerala), online PSC application and exams, virtual courts, e-Health Kerala, THANAL, FRIENDS, K-SMART.

A single cyber attack can affect thousands of citizens. Hence cyber security is a collective or shared responsibility. It is necessary to:

  1. Protect sensitive data (like Aadhar, PAN, bank account details).
  2. Prevent online fraud and scams.
  3. Protect government databases.
  4. Build trust and reputation in digital services.
7.5

Different Types of Cyber Security

TypeWhat it protects
a. Network SecuritySecures networks from intruders using intrusion detection systems, firewalls and VPNs; protects the network’s perimeter.
b. Application SecurityProtects software and devices — secure programs, checking for weaknesses, firewalls, regular patching.
c. Information SecurityAlso called data security; protects confidentiality, integrity and availability of data via encryption and access control.
d. Endpoint SecurityProtects PCs, smartphones and tablets, from basic antivirus to EDR (Endpoint Detection and Response).
e. Operational SecurityManages permissions and access to data assets — e.g. multi-factor authentication for corporate databases.
f. Cloud SecurityProtects data and infrastructure in cloud computing; a shared responsibility between provider and client.

Data encryption: the process of converting data into a coded form to protect it from unauthorized access. Only a person with the correct key or password can convert it back.

Try Yourself — after 7.5

1. Protecting smart phones and laptops comes under: (a) Network (b) Application (c) Endpoint (d) Cloud security
(c) Endpoint security
2. Which type of security focuses on protecting data confidentiality and integrity?
Information Security (also known as data security)
7.6

Common Cyber Security Threats

a. Phishing Attacks
Attackers pretend to be trusted sources and deceive individuals into sharing confidential information — card numbers, passwords, via deceptive emails and fake websites.
b. Malware
Malicious software: any program designed to damage or exploit a device, service or network. Forms include Virus, Trojan, Worms, Spyware.
c. Ransomware
Malware that takes control of a victim’s files or systems and demands a ransom. Cannot be accessed without a decryption key, promised only upon payment.
d. Man-in-the-Middle (MitM)
The perpetrator covertly intercepts, and may modify, communications between two parties who think they are connecting directly. Common on unsecured Wi-Fi.
e. Denial-of-Service (DoS)
Blocks users from a machine or network by stopping the host’s internet-based services. Targets web servers of banks, media, government sites.
f. Zero-Day Exploits
Hackers exploit a vulnerability before developers know of it, or before a patch exists. Extremely dangerous — little or no time to fix the flaw.
g. Insider threats
Risk from within — disgruntled employees, contractors or anyone with inside access misusing credentials to steal data or disrupt systems.
7.7

Cyber Crimes

Cyber crime refers to illegal activities carried out using computers, mobile devices or the internet. In cyber crimes, digital technologies are the target, the tool or both.

Roles of the computer in cyber crimes
Target
The computer/network itself is attacked. Example: hacking a server, spreading viruses.
Tool
Used to commit the crime directly. Example: phishing emails, online fraud, spreading malware.
Storage device
Used to store illegal data. Example: stolen data, pirated software, illegal content.
Communication medium
Used to trap victims or coordinate crimes. Example: planning crimes via email, chat or social media.

Cyber crimes fall into four major categories: against individuals, property, organizations, and governments/society.

7.7.1 Against Individuals
Identity theft
Stealing and misusing personal information. Using stolen or fake identity information to commit fraud is called identity fraud or theft.
Email spoofing
The e-mail header is forged so the mail appears to originate from one source but was actually sent from another.
Phishing
Online identity theft: acquiring usernames, passwords, card details by pretending to be the original website — mostly banks. Creating such a misleading website is called spoofing. The most widespread financial threat on the Internet.
Pharming
Users are redirected to fake websites by manipulating DNS servers. Phishing is a direct attack; pharming is more like a trap door.
Spamming
Sending multiple copies of unsolicited mails or mass e-mails such as chain letters.
Cyber defamation
Defamation using computers/internet — e.g. publishing defamatory matter on a website or in e-mails.
Cyber stalking
Repeatedly harassing, threatening or following an individual’s activity over the internet.
Cyber bullying
Using digital platforms to insult or embarrass someone, especially repeatedly.
7.7.2 Against Property
Credit card fraud
Fraud using a credit card — generally by learning the card number/details or through a stolen card.
Intellectual Property crimes
i. Software piracy — illegal copying of programs. ii. Copyright infringement — using copyrighted material without permission. iii. Trademarks violations — using trademarks without the holder’s permission. iv. Theft of computer source code.
Internet time theft
Internet hours paid by one person are used by an unauthorized individual.
7.7.3 Against Organizations
Unauthorized accessing of computer
Accessing a computer/network without the owner’s permission — either to change/delete data, or as a computer voyeur who reads or copies confidential information without changing it.
Denial of service
The Internet server is flooded with continuous bogus requests, denying legitimate users the server or crashing it.
Virus
Replicates by attaching to other files/programs. Needs a host to spread; causes data loss or crashes.
Worm
Like a virus but spreads without a host. Self-contained, propagates through networks, consuming resources.
Trojan
An unauthorized program that seems authorized, concealing what it does. Lets attackers access the system or steal data.
Ransomware
A digital kidnapper — encrypts files and demands payment for the decryption key. Payment does not guarantee recovery.
Spyware
Secretly monitors and collects data such as browsing habits or keystrokes.
Email bombing
Sending a large number of mails to an individual, company or mail server, crashing the system.
Salami attack
A large amount of money or data is stolen by taking very small amounts repeatedly so each theft goes unnoticed — like slicing thin pieces of salami.
Logic bomb
An event-dependent program; when the designated event occurs it crashes the computer, releases a virus, or causes other harm.
Data diddling
Altering raw data just before it is processed by a computer, then changing it back after processing is over.
7.7.4 Against Governments / Society
Forgery
Currency notes, revenue stamps, mark sheets etc. forged using computers, high quality scanners and printers.
Cyber terrorism
Use of computer resources to intimidate or coerce people and carry out the activities of terrorism.
Web jacking
Hackers gain access to and control another’s website, and may change its content to fulfil a political objective.

7.8

Cyber Security Controls

Cyber security controls are tools or steps that help keep computers and data safe — three main types.

TypeWhat it does
1. Preventive
(before it happens)		Strong passwords — unique, complex, changed regularly.
Keep software updated — patch vulnerabilities.
Multilevel authentication — Two-Factor Authentication (2FA); password + OTP, or password + biometric.
Firewalls — monitor and control network traffic, blocking unauthorised access.
2. Detective
(identify and alert)		Antivirus software — detects, prevents and removes malware by scanning files, emails and websites; must be kept updated.
Alerts — e.g. an alert when someone logs in from a new device.
3. Corrective
(after it happens)		Reinstalling a clean OS or app after infection. Resetting a hacked password and removing unauthorized users.

Cyber security focuses on prevention rather than cure.

Cryptography, Hashing and Digital Signatures
Cryptography
Protecting information by converting it into a secret code. Readable data (plain text) is encrypted into an unreadable form (cipher text); only authorized users with the correct key can decrypt it. Used in online banking and secure messaging.
Hashing
Uses a mathematical function to convert data into a fixed-length value called a hash — a unique digital fingerprint that verifies the data has not been changed.
Digital signatures
Use cryptography and hashing to prove the identity of the sender and ensure a message or document cannot be denied later.

Try Yourself — after 7.8

1. Antivirus software is an example for: (a) Preventive (b) Detective (c) Corrective (d) Legal control
(b) Detective control
2. What is multilevel authentication?
Also called Two-Factor Authentication (2FA). Requires more than one method to verify identity, e.g. password and OTP, or password and biometric.
3. Mention any two characteristics of a strong password.
Any two of: unique (not reused), complex, uses letters/numbers/symbols, avoids personal information, changed regularly.

Cyber Security Do’s and Don’ts

Do’sDon’ts
Use strong passwords with letters, numbers and symbols.Do not share passwords or OTPs with anyone. Do not save passwords on public or shared computers. Do not use the same password for multiple accounts. Do not over share personal information online.
Verify links and emails before clicking or downloading anything.Do not click on unknown or suspicious links in emails or messages.
Download apps and files only from trusted sources and keep them updated.Do not download apps or files from untrusted websites and do not ignore software and app updates.
Lock your devices using PIN, password or biometrics.Do not leave devices unlocked or unattended.
Use antivirus software and scan your device regularly.Do not ignore antivirus warnings or alerts.
Log out after using email or social media on shared computers.Do not stay logged in on shared or public computers.

Report suspicious messages to a trusted adult or authority.Do not respond to online threats or fake prize messages.
Backup important data like assignments and projects.Do not rely on a single copy of important data.
Use privacy settings on social media accounts.Do not accept friend requests from unknown people.
7.10

Legal and Ethical Behaviour in Cyber Space

Legal behaviour
Following the laws and rules on the use of computers and the internet: not hacking systems; not spreading viruses; not stealing personal or financial information; not sharing illegal or copyrighted content. Cyber laws protect users, data and digital systems, and help prevent cyber crimes.
Ethical behaviour
Doing what is morally right even when there is no direct law: respecting others’ privacy; not bullying or harassing people online; not spreading fake news; using digital resources honestly; giving credit to original creators; using the internet responsibly.

The Information Technology Act, 2000 — passed by the Indian Parliament to provide legal recognition to electronic records and digital signatures.

The Information Technology Amendment Bill, 2008 — amended the above act to strengthen cyber security laws and address emerging cyber threats.
