6.1

What is a Computer Network?

A computer network is an interconnection among two or more computers or computing devices. Such interconnections allow computers to share data and resources among each other.

Hosts (also called nodes) include servers, desktops, laptops and cellular phones. Networking devices — switch, router, modem — connect them together. The main goal of a network is to let devices and people communicate, share resources, and work together easily.

Four kinds of networks in daily life

Social NetworksFriends and families connected through relationships.
Mobile NetworksPhones connected for calls, messages and internet.
Computer NetworksComputers sharing files, videos and information.
Service NetworksAirlines, railways, banks and hospitals connecting people, places and services.
6.2

Data Communication

Data Communication is the process of transmitting digital data between two or more devices through a communication medium such as cables or wireless signals. The goal: to exchange information efficiently and accurately.

Five components

ComponentDefinition
SenderThe device that sends the data.
ReceiverThe device that receives the data.
MessageThe actual information or data to be transmitted.
MediumThe path through which data travels (cables, airwaves).
ProtocolA set of rules that governs data transmission (e.g. TCP/IP).
⚠ RememberSender → Medium → Receiver is the path the Message travels. Protocol isn't a step in that line — it's the rulebook governing the whole link.

Key terms

NodeAny active device connected to a network that participates in data exchange — computers, servers, printers, routers, switches, modems, smartphones, IoT devices.
BandwidthThe amount of data that can be transmitted in a given time. Wide pipe = high bandwidth = more data/second. Narrow pipe = low bandwidth = slower.
LatencyThe time taken for data to travel from source to destination — i.e. delay in data transmission.
Bit RateThe number of bits transmitted per second (bps).

6.3.1

Transmission Media

The channel through which data travels between sender and receiver — split into Guided (Wired) and Unguided (Wireless).

Guided (Wired) Media

TypeAdvantagesLimitations
Twisted Pair CableInexpensive, easy to install; short distanceProne to interference; limited bandwidth
Coaxial CableBetter noise protection; higher bandwidthThicker, costlier, harder to install
Optical Fibre CableExtremely high speed; immune to EM interferenceExpensive; fragile, difficult to install

Unguided (Wireless) Media

TypeAdvantagesLimitations
Radio WavesPenetrates buildings; supports mobilityExternal interference; limited security
MicrowavesHigh data rate; satellite/cellular useNeeds line-of-sight; weather-affected
Infrared WavesSecure, simple; no radio interferenceLimited range; needs direct line-of-sight
Satellite CommunicationWide geographical coverage; TV/GPSVery costly; signal delay

Choice of medium depends on distance, cost, data rate and environment — twisted pair for small LANs, optical fibre for high-speed backbones, wireless for mobile or remote use.

6.4

Network Devices

Hardware components that connect computers and other electronic devices together to form a network.

ModemBridges digital computers and analog telephone lines. Modulation converts digital → analog (sending); demodulation converts analog → digital (receiving).
NICNetwork Interface Card — the interface between a computer and the network; a circuit board on the motherboard. Holds the unique MAC address.
RepeaterExtends network coverage by amplifying and retransmitting weak signals (attenuation = signal weakening over distance). Does not filter or manage traffic.
RouterConnects multiple networks together (e.g. LAN to Internet), using IP addresses to route packets to the correct destination.
GatewayConnects two networks that use different protocols — a translator at the network's edge. Performs protocol conversion, data handling, routing/forwarding, and response transmission.

Device comparison

DeviceKey distinguishing fact
HubBroadcasts to every port; no MAC check, no filtering
SwitchUses a MAC address table; forwards to one specific port
IP AddressA unique numerical identifier for each device on a network. IPv4 (e.g. 192.168.1.1) or IPv6 (larger address space).
ServerA powerful computer providing services, resources and data to client computers — storage, resource management, authentication, hosting, security, backup.
FirewallA security barrier between a trusted internal network and an untrusted external network (like the Internet), controlling traffic by predefined rules.
6.5

Network Topology

Network Topology is the arrangement or layout in which devices (nodes) are connected. It can be physical (actual cable layout) or logical (the way data moves). The chapter covers five common topologies — bus, star, ring, mesh, tree — and then adds a sixth, hybrid, built by combining the others.

The Internet

The Internet is a global network connecting millions of computers and devices worldwide, using standard protocols like TCP/IP.

Protocols for Data Communication

ProtocolPurpose
HTTPFetches web pages. Not encrypted.
HTTPSSecure HTTP; uses SSL to encrypt passwords, banking data.
FTPTransfers files between client and server.
TCP/IPFoundation of the Internet — packets, addressing, routing.
SMTPSends outgoing email. Port 25.
POP3Retrieves email; downloads then deletes. Port 110 (995 secure).
IMAPRetrieves email; keeps synced on server. Port 143 (993 secure).
MIMELets email carry images, audio, video, attachments.
DNSTranslates domain names into IP addresses.
